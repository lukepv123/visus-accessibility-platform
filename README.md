# VISUS — Accessibility Education Platform

**VISUS** is an educational platform focused on **digital accessibility**, designed to improve access for blind and visually impaired students in online learning environments.

Developed as an academic capstone project (TCC), VISUS demonstrates how accessibility features can be integrated from the ground up — or incorporated later — in a structured and scalable way.

---

## 🎯 Focus
- Digital inclusion  
- Real-world usability  
- Accessible-first design
